# Пой! Танцуй!

Сайт для музыкальной вечеринки: участники выбирают случайный номер от **1 до 20**, а затем поют караоке или танцуют под выбранное видео.

## Как пользоваться

1. Выберите что хотите: **«Песни»** или **«Танцы»**.
2. Случайным образом выберите номер от 1 до 20 и нажмите на него.
3. На открывшейся странице включите видео. Для просмотра на весь экран используйте кнопку полноэкранного режима видеоплеера.
4. Чтобы вернуться к номерам, нажмите **«Назад к выбору»** или воспользуйтесь кнопкой «Назад» в браузере.

Выбранные номера подсвечиваются **зелёным**. Чтобы сбросить все отметки песен и танцев, нажмите на зелёный квадратик или надпись **«Уже выбирали»** на главной странице. Видео при этом не удаляются.

Отметки сохраняются в `localStorage` текущего браузера. В другом браузере или после очистки данных сайта история будет отдельной или сбросится.

## Анимация для китайских песен

Для студентов из Китая предусмотрена праздничная анимация: большое сердце с надписью **«我们爱你们！»** («Мы вас любим!»), красные фонарики, рыбки и знаки удачи **福**.

В текущем `jss/main.js` анимация включена для песен **5, 8 и 20**. Чтобы переключить её найдите в функции `setupPlayer` строку:

```javascript
if (type === "karaoke" && (n === 17 || n === 18)) showChinaCelebration();
```

Замените цифры на нужную вам. Например:

```javascript
if (type === "karaoke" && (n === 17 || n === 18)) showChinaCelebration();
```

Условие `type === "karaoke"` означает, что анимация срабатывает только для песен, но не для танцев.

### Как отключить анимацию

В файле `jss/main.js` удалите эту строку с вызовом `showChinaCelebration()` или закомментируйте её, добавив `//` в начале. Например:

```javascript
// if (type === "karaoke" && (n === 5 || n === 8 || n === 20)) showChinaCelebration();
```

Остальной код анимации удалять не обязательно: без вызова он не запустится.

## Видео

Для воспроизведения добавьте видео в папки `media/karaoke` и `media/dances`. Номер в имени файла должен совпадать с номером кнопки:

```text
media/
├── dances/
│   ├── dance_1.mp4
│   ├── dance_2.mp4
│   ├── ...
│   └── dance_20.mp4
└── karaoke/
    ├── karaoke_1.mp4
    ├── karaoke_2.mp4
    ├── ...
    └── karaoke_20.mp4
```

Вместо `.mp4` можно использовать `.webm`, `.mov` или `.m4v`: сайт проверяет эти расширения по очереди. Для каждого номера достаточно одного файла. Воспроизведение зависит от поддержки формата и кодека браузером; рекомендуемый вариант — **MP4 с видео H.264 и аудио AAC**.

Если файл не найден или браузер не может его воспроизвести, на странице видео появится сообщение.

## Структура проекта

```text
├── index.html                    # Главная страница
├── README.md                     # Описание проекта
├── css/
│   └── main.css                  # Стили
├── jss/
│   └── main.js                   # Кнопки, видео, отметки и анимация
├── templates/
│   ├── dance_movies.html         # Шаблон страницы танца
│   └── karaoke_movies.html       # Шаблон страницы песни
└── media/
    ├── dance-sticker.png         # Фоновый стикер
    ├── dances/                   # Видео для танцев
    └── karaoke/                  # Видео для караоке
```

## Запуск

1. Сохраните файлы и папки в той же структуре, что в репозитории.
2. Добавьте видео в соответствующие папки `media`.
3. Откройте **`index.html`** двойным щелчком в браузере.

Поведение локальных файлов и сохранения отметок может зависеть от браузера. Если видео не открываются или отметки не сохраняются, запустите локальный сервер из папки проекта:

```bash
python -m http.server 8000
```

Затем откройте в браузере <http://localhost:8000>.
